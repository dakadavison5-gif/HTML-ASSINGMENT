# HTML Website Development Assignment

## Introduction

This project demonstrates the development of a simple static website using HTML. The website was created using different HTML elements, semantic elements, attributes, and basic web development practices. The project also demonstrates the use of Git and GitHub for version control.

---

# Question 1: Website Type and Content

The website created is a simple static website designed around a specific topic. It contains relevant information, navigation links, images, sections, tables, lists, and other HTML content related to the chosen website topic.

---

# Question 2: HTML Elements

 1. Which 5 elements were most challenging to implement and why?

The five most challenging elements were `<figure>`, `<figcaption>`, `<table>`, `<details>`, and `<aside>` because they required careful structuring and understanding of how different types of content should be organized.

 2. How were semantic elements used to structure the content?

Semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, and `<footer>` were used to divide the website into meaningful areas and make the structure of the content clear and easy to understand.

 3. Which element was most useful for organizing the layout and why?

The `<section>` element was very useful because it allowed the content to be divided into separate and organized parts, making the website easier to structure and navigate.

---

# Question 3: HTML Attributes

 1. Which 3 attributes were essential for making the website functional?

The three important attributes were `href`, `src`, and `alt`. The `href` attribute was used for navigation links, `src` was used to display images, and `alt` provided alternative descriptions for images.

 2. How were the `class` and `id` attributes used differently?

The `class` attribute is normally used to identify multiple elements that can share the same styling or behavior, while the `id` attribute identifies one specific element. The website mainly used `id` to identify sections and connect them to navigation links.

 3. Which attribute helped improve user experience the most and why?

The `alt` attribute helped improve user experience because it provides alternative text when an image cannot be displayed and also helps users who use screen readers.

---

# Question 4: Development Process

 1. How did you plan your website structure before coding?

I first decided on the type and purpose of the website, then planned the main sections such as the header, navigation, main content areas, images, and footer before starting to write the HTML code.

 2. What was your approach to testing and debugging your HTML?

I tested the website regularly in a web browser, checked whether the links and images worked correctly, and corrected missing tags, incorrect attributes, and other HTML errors whenever they appeared.

 3. What challenges did you face and how did you overcome them?

The main challenges were understanding some HTML elements, organizing the content correctly, and fixing small coding errors. I overcame these challenges by checking the HTML structure carefully, testing the website, and making corrections until it worked properly.

---

# Question 5: Git & GitHub Implementation

 1. What Git commands did you use during development?

The main Git commands used were:

```bash
git init
git add .
git commit -m "Initial commit"
git status
git log
git branch
git remote add origin
git push
```

These commands were used to initialize the repository, track changes, create commits, check the repository status, connect the project to GitHub, and upload the project.

 2. How many commits did you make and what was your commit message strategy?

The number of commits depended on the progress made during development. Commit messages were kept short and descriptive, such as `Initial commit`, `Added website structure`, `Added content`, and `Updated HTML`.

 3. Why is version control important for web development projects?

Version control is important because it keeps track of changes, allows developers to return to previous versions, helps prevent loss of work, and makes it easier to manage and collaborate on projects.

---

# Question 6: Code Quality & Best Practices

 1. How did you ensure your HTML was valid and error-free?

I checked that all HTML tags were properly opened and closed, used the correct HTML structure, checked attributes, and tested the website in a web browser to identify and fix errors.

 2. What best practices did you follow for writing clean, readable code?

I used proper indentation, meaningful headings, organized sections, clear formatting, descriptive attributes, and comments where necessary to make the code easier to read and understand.

 3. How would you improve your website if you had more time?

If I had more time, I would improve the website by adding CSS for better design, JavaScript for more interactive features, improving responsiveness for mobile devices, adding more content, and improving the overall user experience.
